# 函数注册表

> 约定：代码每次增删改后同步更新本表，便于快速查阅函数签名与职责。

| 函数/类 | 签名 | 说明 | 所在文件 |
|---|---|---|---|
| `Settings` | `class Settings(BaseSettings)` | 全局配置：env 前缀 `CALLBOT_`、`.env` 加载、忽略未知字段 | `src/callbot/config.py` |
| `setup_logging` | `def setup_logging(level: str = "INFO") -> None` | 初始化根日志器：stdout 输出 + 统一格式 | `src/callbot/logging.py` |
| `computeAudioLevel` | `function computeAudioLevel(samples: Float32Array): number` | 计算音频帧音量等级 0-100（RMS 0.1 满格） | `frontend/src/utils/audio.ts` |
| `validate_message` | `def validate_message(raw: str) -> SignalMessage \| None` | 解析校验 WebRTC 信令 JSON，非法返回 None | `src/callbot/channel/webrtc.py` |
| `Session` | `@dataclass class Session` | 单路 WebRTC 会话（peer + id + tracks） | `src/callbot/channel/webrtc.py` |
| `SessionManager` | `class SessionManager`（add/remove/get/count） | 会话登记、查询与清理 | `src/callbot/channel/webrtc.py` |
| `_parse_ice_candidate` | `def _parse_ice_candidate(candidate: dict[str, Any]) -> RTCIceCandidate \| None` | 把浏览器 toJSON() 的 ICE 候选解析为 aiortc RTCIceCandidate（aiortc 1.16 无 from_sdp） | `src/callbot/channel/webrtc.py` |
| `handle_signaling` | `async def handle_signaling(websocket: WebSocket, manager: SessionManager) -> None` | 处理信令连接：offer/answer/ICE 交换 + 音轨回声环回 | `src/callbot/channel/webrtc.py` |
| `create_app` | `def create_app() -> FastAPI` | FastAPI 应用工厂（含 /ws/signal 路由） | `src/callbot/api/app.py` |
| `SignalingClient` | `class SignalingClient`（connect/send/onMessage/close） | 浏览器端 WebSocket 信令客户端 | `frontend/src/api/signaling.ts` |
