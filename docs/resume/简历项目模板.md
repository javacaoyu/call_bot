## 项目介绍（一段话）

**callbot 外呼机器人——实时流式语音对话引擎 + 话术编排平台**（独立开发，WSL2 + RTX 4060 单机部署）。产品形态为「音频流进 → 智能体对话 → 音频流出」：浏览器采集 16kHz PCM 经 WebSocket 直传后端，VAD 端点检测 → 流式 ASR → LLM 编排 → 流式 TTS 首 token 即合成回放，全链路支持**全双工打断**（客户抢话即停即答）。核心能力包括：ASR/LLM/TTS 三环节**本地↔云端配置驱动热切换**（FunASR/CosyVoice2 本地模型与火山引擎、千问云端服务）；基于 AgentScope 的**意图中枢话术引擎**——可视化流程图编排（开场白→意图识别→处理节点循环→结束语自动挂断）、多智能体共享记忆、工具库（HTTP 配置式/代码插件式）；场景管理、人设与变量插槽、行业模板库一键实例化、流程发布/回滚版本化、通话记录与合规预留。测试 215 个用例全绿（pytest + vitest），核心链路延迟优化至 TTFT < 500ms 级。

## 技术栈（技术名词，逗号分隔）

Python, FastAPI, WebSocket, WebRTC(aiortc), Vue 3, TypeScript, Vite, Tailwind CSS v4, vue-flow, PostgreSQL 16, pgvector, SQLAlchemy 2.x, Docker, AgentScope 2.x, DeepSeek API, 火山引擎豆包语音, 千问(阿里云)语音识别与合成, FunASR Paraformer, CosyVoice2-0.5B, Silero VAD, PyTorch, WSL2 Ubuntu, RTX 4060 GPU, UV, fnm, pytest, vitest, ruff

## 个人职责（有序列表）

1. 独立完成产品技术方案设计：依据 PRD/WBS 拆解 10 个阶段、120 人日的开发计划，按里程碑（单链路半双工 → 全双工打断 → 三环节切换 → 可视化编排）迭代交付
2. 设计并实现端到端实时语音管线：WebRTC 信令 + 16kHz PCM 直传、Silero VAD 状态机、流式 ASR/TTS 集成，将端到端首字响应（TTFT）控制在 500ms 级
3. 实现全双工打断机制：VAD 起音 + ASR 转写双路触发，打断时同步停止 TTS 播放、关闭 LLM 生成流，并以「已完整说出的句子」重建对话上下文，保证语义不丢
4. 抽象三环节 Provider 体系（ASR/LLM/TTS）：本地模型（FunASR/CosyVoice2）与云端服务（火山/千问/DeepSeek）配置驱动切换，Web 面板热更新，单例进程级共享
5. 基于 AgentScope 构建话术编排引擎：意图中枢状态机（关键词快路径 + LLM 结构化意图分类）、多智能体共享记忆（一次外呼一个共享状态）、打断上下文注入
6. 开发可视化流程图编辑器（vue-flow）：四类节点拖拽编排、连线规则校验、意图/话术属性面板、草稿/发布/版本回滚机制
7. 设计工具系统三轨（HTTP 配置式 / Python 代码插件 / 内置基础工具），工具经 AgentScope Toolkit 注入处理节点，实现 ReAct 工具调用能力
8. 建设业务数据层：场景、人设、客户、流程图、通话记录（转写气泡流 JSONB）的表结构设计与 API 实现；通话状态自动判定（接通/未接）
9. 建立工程质量保障：215 个自动化测试（后端 pytest + 前端 vitest）、ruff/vue-tsc 静态检查、函数注册表文档、Conventional Commits + 分支规范
10. 沉淀关键工程问题解决方案：云端 ASR 句级修订语义收尾、VAD 端点与打断窗口竞态（边缘触发端点补发）、多标签页噪音通话记录治理、测试数据污染生产库防护
